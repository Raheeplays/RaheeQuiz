    SKETCHWARE PRO INTEGRATION GUIDE FOR NATIVE DOWNLOADS & WEBVIEW
==============================================================================
Rahee Quiz App APK Download Feature Support Setup Guide

This guide describes exactly how to implement the WebView Download Listener 
inside Sketchware Pro in two different ways:
  METHOD A: Creating a Custom Java Class (Recommended for clean architecture)
  METHOD B: Raw "Add Source Directly" block (Easiest & Fastest, no extra file)

And explains how to handle required permissions and imports!

------------------------------------------------------------------------------
STEP 1: ADD PERMISSIONS IN SKETCHWARE PRO
------------------------------------------------------------------------------
To save files (PDF certificates, OMR sheets, images, etc.) to the Android 
Downloads folder, your app needs Storage Permission.

1. Open your project in Sketchware Pro.
2. Click on the 3-dots menu button in the top right corner.
3. Select "App Parent / Manifest Manager" or "Permission" menu.
4. Toggle on or add the following permissions:
   - android.permission.INTERNET
   - android.permission.WRITE_EXTERNAL_STORAGE
   - android.permission.READ_EXTERNAL_STORAGE
5. (Optional) Alternatively, you can add them manually under "AndroidManifest.xml" 
   section in Sketchware Pro:
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" android:maxSdkVersion="28" />
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />

------------------------------------------------------------------------------
METHOD A: CREATING THE NATIVE JAVA FILE INSIDE SKETCHWARE PRO (RECOMMENDED)
------------------------------------------------------------------------------
If you want to use the full `WebViewDownloadHelper.java` class directly:

1. In Sketchware Pro, open your project.
2. Click the bottom-left folder icon or click on "Local Library / Java" section, 
   then click "Java" (or "Developer Tools" -> "Java Manager").
3. Click the "+" button to add a new Java file.
4. Name the file: WebViewDownloadHelper
5. Open the newly created `WebViewDownloadHelper.java` and paste the full 
   contents of the standard code. (Make sure the first line matches your package name:
   e.g. `package RaheeQuiz.in;` or whatever your package name is configured to be!)
6. Next, open your Main Activity (e.g. `MainActivity.java` inside Sketchware).
7. Scroll to the `onCreate` event or open the Flow logic view.
8. Add an `Add Source Directly` block inside the onCreate event, and paste 
   this Download Listener attachment code:

       mywebview.setDownloadListener(new android.webkit.DownloadListener() {
           @Override
           public void onDownloadStart(String url, String userAgent, String contentDisposition, String mimeType, long contentLength) {
               WebViewDownloadHelper.handleDownload(MainActivity.this, url, userAgent, contentDisposition, mimeType);
           }
       });

   *Note: Change `mywebview` to the exact name of your WebView widget in Sketchware! 
          Change `MainActivity` if your activity has a different name.*

------------------------------------------------------------------------------
METHOD B: OVERALL "ADD SOURCE DIRECTLY" BLOCK IN ONCREATE (FASTEST MIGRATION)
------------------------------------------------------------------------------
If you do not want to create an extra Java file, you can compile everything 
directly inside your Activity class using Sketchware's "Add Source Directly" block.

Open the Activity's `onCreate` event in Sketchware Pro:
1. Drag and drop an "Add Source Directly" block inside `onCreate`.
2. Paste this self-contained script directly inside the block:

```java
// Paste this directly inside the "Add Source Directly" block inside onCreate!

mywebview.setDownloadListener(new android.webkit.DownloadListener() {
    @Override
    public void onDownloadStart(final String url, final String userAgent, final String contentDisposition, final String mimeType, long contentLength) {
        if (url == null || url.trim().isEmpty()) {
            return;
        }

        // Handle Base64 PDFs (certificates/OMR sheets generated on the fly)
        if (url.startsWith("data:")) {
            try {
                String currentMime = (mimeType == null || mimeType.trim().isEmpty()) ? "application/pdf" : mimeType;
                String suffix = ".pdf";
                if (currentMime.contains("png")) suffix = ".png";
                else if (currentMime.contains("jpg") || currentMime.contains("jpeg")) suffix = ".jpg";

                final String fileName = "Rahee_Download_" + System.currentTimeMillis() + suffix;
                int commaIndex = url.indexOf(",");
                if (commaIndex == -1) {
                    SketchwareUtil.CustomToast(getApplicationContext(), "Invalid data package URL", 0xFFFFFFFF, 12, 0xFFE53935, 5, SketchwareUtil.CENTER);
                    return;
                }
                String base64Content = url.substring(commaIndex + 1);
                final byte[] fileBytes = android.util.Base64.decode(base64Content, android.util.Base64.DEFAULT);

                // Scoped Storage Write Block for Android 10+
                if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.Q) {
                    android.content.ContentValues values = new android.content.ContentValues();
                    values.put(android.provider.MediaStore.MediaColumns.DISPLAY_NAME, fileName);
                    values.put(android.provider.MediaStore.MediaColumns.MIME_TYPE, currentMime);
                    values.put(android.provider.MediaStore.MediaColumns.RELATIVE_PATH, android.os.Environment.DIRECTORY_DOWNLOADS);

                    android.net.Uri collectionUri = android.provider.MediaStore.Downloads.EXTERNAL_CONTENT_URI;
                    android.net.Uri fileUri = getContentResolver().insert(collectionUri, values);

                    if (fileUri != null) {
                        java.io.OutputStream os = getContentResolver().openOutputStream(fileUri);
                        if (os != null) {
                            os.write(fileBytes);
                            os.flush();
                            os.close();
                            SketchwareUtil.CustomToast(getApplicationContext(), "File Saved to Downloads: " + fileName, 0xFFFFFFFF, 12, 0xFF4CAF50, 5, SketchwareUtil.CENTER);
                        }
                    }
                } else {
                    // Fallback for older Android versions
                    java.io.File path = android.os.Environment.getExternalStoragePublicDirectory(android.os.Environment.DIRECTORY_DOWNLOADS);
                    if (!path.exists()) {
                        path.mkdirs();
                    }
                    java.io.File file = new java.io.File(path, fileName);
                    java.io.FileOutputStream fos = new java.io.FileOutputStream(file);
                    fos.write(fileBytes);
                    fos.flush();
                    fos.close();
                    SketchwareUtil.CustomToast(getApplicationContext(), "Saved into directory: " + file.getAbsolutePath(), 0xFFFFFFFF, 12, 0xFF4CAF50, 5, SketchwareUtil.CENTER);
                }
            } catch (Exception e) {
                e.printStackTrace();
                SketchwareUtil.CustomToast(getApplicationContext(), "Download error: " + e.getMessage(), 0xFFFFFFFF, 12, 0xFFE53935, 5, SketchwareUtil.CENTER);
            }
            return;
        }

        // Handle standard Server HTTP / HTTPS links
        try {
            android.app.DownloadManager.Request request = new android.app.DownloadManager.Request(android.net.Uri.parse(url));
            request.setMimeType(mimeType);

            // Cookies forwarder
            String cookies = android.webkit.CookieManager.getInstance().getCookie(url);
            request.addRequestHeader("cookie", cookies);
            request.addRequestHeader("User-Agent", userAgent);

            request.setDescription("Downloading file from Rahee...");
            String filename = android.webkit.URLUtil.guessFileName(url, contentDisposition, mimeType);
            request.setTitle(filename);

            if (android.os.Build.VERSION.SDK_INT < android.os.Build.VERSION_CODES.Q) {
                request.allowScanningByMediaScanner();
            }

            request.setNotificationVisibility(android.app.DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED);
            request.setDestinationInExternalPublicDir(android.os.Environment.DIRECTORY_DOWNLOADS, filename);

            android.app.DownloadManager manager = (android.app.DownloadManager) getSystemService(Context.DOWNLOAD_SERVICE);
            if (manager != null) {
                manager.enqueue(request);
                SketchwareUtil.CustomToast(getApplicationContext(), "Starting Download: " + filename, 0xFFFFFFFF, 12, 0xFF4CAF50, 5, SketchwareUtil.CENTER);
            }
        } catch (Exception e) {
            e.printStackTrace();
            SketchwareUtil.CustomToast(getApplicationContext(), "Download failed: " + e.getMessage(), 0xFFFFFFFF, 12, 0xFFE53935, 5, SketchwareUtil.CENTER);
        }
    }
});
```

*Note: In the code above, `SketchwareUtil.CustomToast` is used to trigger fully integrated Toast popups styled beautifully. Replace `mywebview` with your exact WebView container name in Sketchware.*

------------------------------------------------------------------------------
PRO-TIP: RECONCILING WITH WEBVIEW SETTINGS IN SKETCHWARE
------------------------------------------------------------------------------
Ensure JavaScript is enabled and that cookies are synchronized for best 
performance inside Android WebView when logged in:

```java
// Inside "Add Source Directly" block, after declaring the Webview:
mywebview.getSettings().setJavaScriptEnabled(true);
mywebview.getSettings().setDomStorageEnabled(true);
mywebview.getSettings().setDatabaseEnabled(true);
if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.LOLLIPOP) {
    android.webkit.CookieManager.getInstance().setAcceptThirdPartyCookies(mywebview, true);
}
```
